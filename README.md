# ماهان عطر — نسخهٔ دمو (آزمایش‌نشده)
## راه‌اندازی
1. `cp .env.example .env` و `DATABASE_URL` پستگرس را تنظیم کنید.
2. `npm install`
3. `npx prisma db push`
4. `npm run db:seed` (۸ دسته و ۲۴ محصول نمونه؛ قیمت‌ها فقط نمونه‌اند)
5. `npm run dev` و باز کردن http://localhost:3000

## پیاده‌سازی‌شده
خانه، فروشگاه (فیلتر/مرتب‌سازی/صفحه‌بندی)، دسته‌بندی، جزئیات محصول، سبد خرید با نوار ارسال رایگان، تکمیل سفارش (ثبت واقعی در دیتابیس با کنترل قیمت و موجودی در سرور)، پیگیری سفارش، مجله (۵ مقالهٔ نمونه)، سوالات متداول (نمونه)، تماس با ما (از متغیرهای محیطی)، جست‌وجوی زنده، نوار پایین موبایل، sitemap و robots.

## هنوز پیاده‌سازی نشده
درگاه پرداخت، ورود/ثبت‌نام و حساب کاربری، پنل مدیریت، علاقه‌مندی، نظرات، کد تخفیف، محدودسازی درخواست‌ها. هزینهٔ ارسال و حد ارسال رایگان نمونه‌اند (lib/config.js).

## توجه
دستور build هر بار seed را اجرا می‌کند (مناسب دمو). بعد از ساخت پنل مدیریت، `node prisma/seed.js &&` را از اسکریپت build حذف کنید.
